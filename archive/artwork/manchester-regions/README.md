# Greater Manchester borough image drafts

These drafts are assembled directly from the ten supplied borough cutouts. No AI-generated shapes are used. The source maps use different scales, so they were aligned to the supplied combined-map screenshot. Small raster overlaps were split between adjacent outlines and enclosed pixel gaps were filled. They are illustrative image assets, not surveyed boundary data.

All full-size views share a 2400 × 1800 canvas and a six-pixel display grid. Separate masks preserve the ten borough regions. The source-colour image keeps the supplied ward detail and colours, with borough borders made stronger. The dark base omits internal ward detail to keep the ten borough boundaries clear.

Each highlighted borough has PNG and lossless WebP versions. Neon green is #dffc3a. The glow is already rendered into the image; it needs no live browser blur. The preview sheet and labelled border key are review material. No website HTML, CSS or JavaScript has been changed to display these drafts.
