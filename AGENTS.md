# Protected retro map

Do not delete or modify the archived retro map, its regional views, assets or animation sources during dead-code cleanup. Removal requires explicit approval naming the retro map.

- No current references does not mean safe to delete. Check archived-feature records first.
- Read `archive/retro-map/README.md` and its source manifest before any cleanup affecting map or landing-page files.
- Keep the dated source ZIP and manifest even if the live landing-page map is removed. A request to remove the map from the visible website does not authorise deleting the archive.
- Shared files, including `index.html` and `data/map-wards.json`, also serve other website features. Restore only the needed map sections; never reset the whole working tree.
- General cleanup requests do not authorise changing map boundaries, deleting reference maps or simplifying detailed ward views.
