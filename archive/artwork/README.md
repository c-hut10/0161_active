# Archived artwork

These files are retained for reference and future image edits. They are not public website assets and are not copied into the Netlify deployment folder.

- `social/`: retired share cards. Every current page uses the 0161 Active logo instead.
- `manchester-region-pixelated*.png`: earlier full-map drafts.
- `manchester-regions/`: source masks, alternate map images, review sheets and the original image pack.

The ten glow images used by the interactive welcome map remain in `img/manchester-regions/hover/`. Keep new drafts and source artwork here, and place only files used by the website in `img/`.
